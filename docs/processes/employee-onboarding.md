## 📋 Detailed Process

### Pre-Start (1 Week Before Day 1)

**Admin & Logistics:**
- [ ] Contract signed
- [ ] Hardware ordered (laptop, etc.) if needed
- [ ] Email account created
- [ ] Tool accounts prepared
- [ ] Workspace prepared (if office)

**Communication:**

**Welcome Email:**
```
Subject: Welcome to important.is! 🎉

Hi [Name],

We're so excited for you to join important.is!

Your start date: [Date]
First day plan: [Brief overview]
What to bring: [If office] or Setup instructions [If remote]

Before you start:
- [Any pre-reading]
- [Forms to complete]
- [Access info]

If you have any questions before day 1, just reach out!

See you soon!

[Your name] & the important.is team
```

**Prep for Team:**
- [ ] Announce new hire to team
- [ ] Assign onboarding buddy
- [ ] Prepare welcome package
- [ ] Plan team intro meeting

---

### Day 1: Welcome! 🎉

**Morning:**

**9:00 - Welcome & Setup (2h)**
- [ ] Tour (if office) or Video walkthrough (if remote)
- [ ] Workstation setup
- [ ] IT setup: email, tools, accounts
- [ ] Welcome package (branded swag if have)
- [ ] First day agenda overview

**11:00 - Team Intro (1h)**
- [ ] Meet everyone (if small team, individually; if larger, group)
- [ ] Everyone shares: role, what they do, fun fact
- [ ] Buddy introduction (dedicated)

**Afternoon:**

**13:00 - Company Overview (1-2h)**
- [ ] Mission, vision, values (interactive, not lecture)
- [ ] History & story
- [ ] How we work
- [ ] Current projects overview
- [ ] Q&A

**15:00 - Role Deep Dive (1h)**
- [ ] Role expectations
- [ ] Goals for first 30/60/90 days
- [ ] Key projects/focus areas
- [ ] Success criteria

**16:00 - Tools & Resources (1h)**
- [ ] Tour of tools (Slack, PM tool, design tools, etc.)
- [ ] Wiki/documentation walkthrough
- [ ] Key resources & where to find things
- [ ] Communication norms

**End of Day:**
- [ ] Check-in: How was day 1?
- [ ] Answer questions
- [ ] Preview tomorrow

---

### Week 1: Foundation

**Goals:**
- Complete admin
- Understand company & culture
- Learn processes
- Start contributing

**Daily Structure:**
- Morning check-in with manager/buddy
- Learning/training time
- Small tasks to get hands dirty
- End of day reflection

**Key Activities:**

**Day 2:**
- [ ] **Strategy deep dive**: Mission, vision, brand sprint, values
- [ ] **Client process overview**: How we work with clients
- [ ] **First small task**: Something achievable, real contribution

**Day 3:**
- [ ] **Technical training**: WordPress, Bricks, our stack
- [ ] **Project management**: Our workflow, tools, standards
- [ ] **Shadow work**: Observe meeting or work session

**Day 4:**
- [ ] **Quality standards**: Code review process, design standards
- [ ] **Communication**: How we communicate (Slack, meetings, async)
- [ ] **Work on real task**: Guided but real project work

**Day 5:**
- [ ] **Week 1 retro**: What learned, questions, feedback
- [ ] **Week 2 plan**: What's coming
- [ ] **Team lunch/social**: (virtual or in-person) bonding time

**Deliverables:**
- [ ] All admin completed
- [ ] All tools access verified
- [ ] Read key docs (mission, values, processes)
- [ ] Complete small real task
- [ ] Give Week 1 feedback

---

### Weeks 2-4: Ramp Up

**Goals:**
- Increasing independence
- Real contributions
- Process mastery
- Team integration

**Week 2:**
- [ ] Take on project component (with support)
- [ ] Participate in client meeting (observer or contributor)
- [ ] Shadow senior on their process
- [ ] 1-on-1 with manager: Progress check

**Week 3:**
- [ ] Own small project or feature
- [ ] Present work to team (show & tell)
- [ ] Start contributing to discussions/decisions
- [ ] 1-on-1: Feedback both ways

**Week 4:**
- [ ] Fully participating in team rhythms
- [ ] Contributing independently (but support available)
- [ ] Month 1 review: Goals, progress, feedback
- [ ] Set Month 2 goals

**Manager Check-ins:**
- Week 1: Daily
- Week 2-4: 2-3x per week
- Focus: Questions, blockers, progress, feedback

---

### Month 2-3: Full Speed

**Goals:**
- Fully productive
- Independent contributor
- Living values
- Team member fully integrated

**Month 2:**
- [ ] Full project ownership
- [ ] Less hand-holding needed
- [ ] Proactive communication
- [ ] Bi-weekly 1-on-1s

**Month 3:**
- [ ] 90-day review: Comprehensive feedback
- [ ] Performance vs. expectations
- [ ] Growth areas identified
- [ ] Career development discussion
- [ ] Compensation review (if applicable/promised)

**Deliverables:**
- [ ] Successfully delivered project(s)
- [ ] Demonstrating values in work
- [ ] Integrated w team
- [ ] Clear on growth path

## 👥 Onboarding Buddy System

**Buddy Role:**
- Go-to person for questions
- Cultural guide
- Social connector
- Not manager (peer support)

**Buddy Responsibilities:**
- [ ] Daily check-ins Week 1
- [ ] Answer questions (or direct to right person)
- [ ] Lunch/coffee hangouts
- [ ] Introduce to team socially
- [ ] Share unwritten rules & norms
- [ ] Be friendly face!

**Buddy Selection:**
- Peer or slightly more senior
- Good culture fit themselves
- Patient & helpful
- Good communicator

## 🔄 Check-in Schedule

**Week 1:**
- Daily end-of-day check-ins (15 min)
- Friday: Week 1 retro (30 min)

**Weeks 2-4:**
- 2-3x per week (30 min)
- End of Month 1: 30-day review (60 min)

**Months 2-3:**
- Bi-weekly 1-on-1s (45 min)
- End of Month 3: 90-day review (90 min)

**After Month 3:**
- Regular 1-on-1 schedule (weekly or bi-weekly)

## 📊 Success Metrics

**Track:**
- Time to first meaningful contribution
- Time to full productivity
- Onboarding satisfaction (survey)
- 90-day retention rate
- Manager satisfaction with ramp

**Goals:**
- First contribution: < Week 1
- Full productivity: < Month 2
- Onboarding satisfaction: > 4.5/5
- 90-day retention: > 95%

## 💡 Onboarding Tips

**For Manager:**
- ✅ Overcommunicate early
- ✅ Provide structure but also autonomy
- ✅ Regular feedback (positive & constructive)
- ✅ Set clear expectations
- ✅ Celebrate small wins
- ✅ Be patient - learning curve is real

**For New Hire:**
- ✅ Ask questions (no stupid questions!)
- ✅ Take notes
- ✅ Be proactive
- ✅ Communicate challenges early
- ✅ Give feedback on onboarding
- ✅ Be patient with yourself
