## 💻 Core Technology Stack

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Modern CSS, CSS Grid, Flexbox
- **JavaScript (ES6+)** - Vanilla JS preferred, minimal libraries
- **Bricks Builder** - Visual page building

### Backend
- **PHP 8.0+** - Modern PHP
- **WordPress** - CMS platform
- **MySQL 8.0+** - Database

### Hosting & Infrastructure
- **Recommended Hosts:**
  - Kinsta (premium)
  - WP Engine (managed WordPress)
  - Cloudways (flexible)
  - SiteGround (good value)

- **Requirements:**
  - PHP 8.0+
  - MySQL 8.0+ or MariaDB
  - HTTPS/SSL
  - SSH access (preferred)
  - WP-CLI access (preferred)

## 🔄 Tool Evaluation Process

### Before Adding New Tool

**Questions:**
- What problem does it solve?
- What's the current solution?
- Cost vs benefit?
- Learning curve?
- Team buy-in?
- Can we trial it?
- Exit strategy?

**Process:**
1. Identify need
2. Research options (3-5)
3. Trial top 2-3
4. Team decision
5. Implementation
6. Training if needed
7. Evaluate after 30-90 days
