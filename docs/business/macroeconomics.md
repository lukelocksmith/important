## 💵 Cash Flow Management

### Cash Flow Components

**Operating Cash Flow:**
```
Net profit:              199,500 PLN
+ Depreciation:           10,000 PLN
- Working capital changes: -20,000 PLN
Operating CF:            189,500 PLN
```

**Investing Cash Flow:**
```
Equipment/software:       -30,000 PLN
```

**Financing Cash Flow:**
```
Loans/equity:              50,000 PLN
Distributions:            -50,000 PLN
Financing CF:                  0 PLN
```

**Net Cash Flow:**
```
Operating:               189,500 PLN
Investing:               -30,000 PLN
Financing:                     0 PLN
Net increase:            159,500 PLN
```

### Cash Runway

**Burn Rate = Monthly Operating Expenses**

Example:
```
Monthly expenses:          40,000 PLN
Cash on hand:             240,000 PLN
Runway = 240k / 40k = 6 months
```

**Target:**
- Early stage: 3-6 months
- Growth stage: 6-12 months
- Mature: 12+ months

## 💸 Customer Economics

### Acquisition Economics

```
CAC (Customer Acquisition Cost) = Marketing + Sales costs / New customers

Example:
  Marketing/sales costs:    80,000 PLN/year
  New clients:              20 clients
  CAC = 4,000 PLN per client
```

### Lifetime Value

```
LTV = Avg project value × # projects × Gross margin

Example:
  Avg project:             30,000 PLN
  Projects per client:     2.5
  Gross margin:            75%
  LTV = 30k × 2.5 × 0.75 = 56,250 PLN
```

### LTV:CAC Ratio

```
LTV:CAC = 56,250 / 4,000 = 14:1

Target ratios:
  Good: > 3:1
  Great: > 5:1
  Excellent: > 10:1
```

## 📊 Key Financial Ratios

### Profitability Ratios

**Gross Margin:**
```
(Revenue - COGS) / Revenue
Target: 70-80%
```

**Net Margin:**
```
Net Profit / Revenue
Target: 20-35%
```

**EBITDA Margin:**
```
EBITDA / Revenue

```

## 🔄 Business Cycle Management

### Seasonal Patterns

**Typical Agency Seasonality:**
- Q1: Strong (new year budgets)
- Q2: Moderate
- Q3: Slower (summer)
- Q4: Strong (use-it-or-lose-it budgets)

**Strategies:**
- Build pipeline in slower months
- Retainers smooth seasonality
- Plan marketing for slow periods
- Cash reserves for lean months

## ⚠️ Financial Risk Management

### Risk Categories

**Revenue Risk:**
- Client concentration
- Market downturn
- Losing key clients

**Mitigation:**
- Diversify client base
- Build retainers
- Multiple revenue streams
- Strong sales pipeline

**Cost Risk:**
- Talent costs rising
- Unexpected expenses
- Fixed cost burden

**Mitigation:**
- Variable cost structure where possible
- Maintain reserves
- Regular financial reviews
- Flexible team structure

**Cash Flow Risk:**
- Late payments
- Project delays
- Rapid growth

**Mitigation:**
- Strict payment terms
- Deposits required
- Active A/R management
- Cash runway monitoring
